# Event Collectives - Event Management System  

## 📌 Introduction  
Event Collectives is an event management system designed to streamline event planning, optimize resources, and enhance efficiency. The platform allows users to create, manage, and search for events, as well as book services like photography, catering, and event decoration.  

## 🚀 Features  
- **Event Creation & Management**: Organize and monitor events from a single platform.  
- **Service Booking**: Book photographers, caterers, decorators, and more.  
- **Admin Panel**: Manage user bookings and responses securely.  
- **User-Friendly Interface**: Designed with a responsive UI using HTML, CSS, JavaScript, and Bootstrap.  
- **Secure Authentication**: Admin login to ensure data privacy.  

## 🏗️ Technologies Used  
- **Frontend**: HTML, CSS, JavaScript, Bootstrap  
- **Backend**: PHP  
- **Database**: MySQL  
- **Development Tools**: Visual Studio Code, XAMPP  
- **Design Tools**: StarUML (for UML diagrams)  

## 🛠️ Installation Guide  
1. Clone the repository:  
   ```sh
   git clone https://github.com/abhinagote/event_collectives.git
   ```  
2. Set up the database:  
   - Import `database.sql` into MySQL.  
   - Update database configurations in `config.php`.  
3. Start the local server (XAMPP/WAMP).  
4. Open the project in the browser: `http://localhost/event-collectives`.
